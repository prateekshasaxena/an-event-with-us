# An Event With Us — Website

Official website for **An Event With Us**, an event management and travel solutions company based in Ujjain, Madhya Pradesh. *Always Behind Your Satisfaction.*

🔗 **Live site:** _add your GitHub Pages / custom domain link here once it's live_

## About

This is a static, multi-page website covering:

- **Home** — hero, stats, work highlights, services, process, testimonials, CTA
- **About** — company story
- **Services** — full list of services offered
- **Work** — case studies of events delivered (with a dedicated detail page per event, e.g. MPISACON 2026)
- **Gallery** — photo gallery with filters and lightbox
- **Contact** — enquiry form, phone/email, and location map

## Tech

Plain HTML, CSS and JavaScript — no build step, no backend, no dependencies. Works by opening `index.html` directly, or by hosting the folder as-is on any static host (GitHub Pages, Netlify, etc.).

## Running locally

Just open `index.html` in a browser — no server or install needed.

## Deploying

This repo is set up to deploy with **GitHub Pages**:

1. Go to **Settings → Pages**
2. Under **Branch**, select `main` and folder `/ (root)`
3. Save — the site goes live at `https://<username>.github.io/<repo-name>/`
